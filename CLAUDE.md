# Reglas del proyecto PlanetUp

## Interacción
- Cuando el usuario tenga que hacer algo manualmente (en Supabase, el terminal, el celular, etc.), dale **un solo paso o campo por mensaje**. Nunca agrupes varios pasos en el mismo mensaje.

## Código
- Mantén el código organizado en **archivos separados**, igual que el resto del proyecto (`data.js`, `store.js`, `logic.js`, `ui.js`, `app.js`…). No metas todo en un solo archivo.

## Diseño
- La app debe **verse bien primero en iPhone** (mobile-first). Cualquier cambio de UI se prueba mentalmente en pantalla de ~390 px antes de darlo por bueno.

## Git
- Al terminar cada cambio funcional, haz **commit y push a main** sin que el usuario tenga que pedirlo.
